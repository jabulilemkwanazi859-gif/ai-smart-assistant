# AI Smart Assistant

Build a modern, responsive web application called "AI Workplace Productivity Assistant" 

that helps professionals automate workplace tasks using AI.

The application should include three core features, each on its own page accessible via 

a sidebar:

1. Smart Email Generator

   - Input fields: recipient, purpose/context, desired tone (formal, friendly, persuasive)

   - Generates a professional email draft

   - Output is editable before the user copies it

2. Meeting Notes Summarizer

   - Large text input for pasting raw meeting notes

   - Summarizes the notes into: key discussion points, decisions made, and action items 

     with owners/deadlines where mentioned

   - Output is editable

3. AI Task Planner / Scheduler

   - Input: list of tasks with optional deadlines and priority

   - Generates a structured daily or weekly schedule, ordered by priority and deadline

   - Output displayed as a clean table or timeline, editable

Requirements:

- Modern dashboard layout with sidebar navigation between the 3 features

- Responsive design (mobile + desktop)

- Clear input and output sections on each page

- All AI outputs must be editable by the user before use

- Include a visible "Responsible AI" disclaimer (e.g. footer note: 

  "AI-generated content may contain errors. Please review before use.")

- Clean, modern, professional SaaS-style design (similar to Notion/Linear aesthetic)

- Use a consistent color scheme and typography across all 3 feature pages
