# AI Workplace Productivity Assistant

## Project Overview
An AI-powered productivity dashboard built to help professionals automate everyday 
workplace tasks. Built as part of the CAPACITI Good AI Skills Acceleration 20 (ASA 20) 
programme, this project demonstrates practical AI implementation, prompt engineering, 
and responsible AI usage in a single integrated platform.

## Features
This application includes the following AI-powered tools, accessible via a sidebar 
dashboard:

1. **Smart Email Generator**
   - Generates professional emails based on recipient, purpose, and desired tone 
     (formal, friendly, persuasive)
   - Output is editable before use

2. **Meeting Notes Summarizer**
   - Summarizes long meeting notes into key discussion points, decisions, and action 
     items with deadlines
   - Output is editable before use

3. **AI Task Planner / Scheduler**
   - Generates a prioritized daily/weekly schedule from a list of tasks
   - Orders tasks by priority and deadline

## Tools Used
- **Lovable AI** – application build and UI/UX design
- **React** + **TypeScript** – frontend framework
- **Tailwind CSS** – styling
- **Supabase** – backend/database integration
- **Lovable Cloud** – secure server-side AI generation

## Setup Instructions
1. Clone this repository:
   git clone https://github.com/jabulilemkwanazi859-gif/ai-smart-assistant.git

2. Install dependencies:
   npm install

3. Run the development server:
   npm run dev

## Responsible AI Usage

retain full control to edit all AI outputs before acting on them.
